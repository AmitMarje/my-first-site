# My First Site

## Project overview
This is a simple website about me. I built it to learn the basics of how hosting works.

## Technologies used
- **HTML**: structure and content of the page (headings, paragraph, list, link and image)
- **CSS**: styling, such as fonts, spacing and image size
- **Git and GitHub**: storing the project in a repository and tracking changes through commits
- **GitHub Pages**: hosting the site and giving it a public URL
- **Visual Studio Code**: writing and editing the code on my laptop

## Hosting Platform
I used GitHub Pages to host this site.My code was already stored in a GitHub repository, so publishing it only meant turning on one setting.

## Deployment instructions

### 1. Create the repository
1. Log in to [GitHub](https://github.com).
2. Click the + icon (top right) and choose New repository.
3. In Repository name, type `my-first-site`.
4. Select Public.
5. Tick Add a README file.
6. Click Create repository.

### 2. Upload the website files
1. On the repository page, click Add file -> Upload files.
2. From your project folder, select the three files inside it: `index.html`, `style.css` and `image.jpg`. Drag them into the browser window. Upload the files themselves, not the folder that contains them, so they sit at the top level of the repository.
3. Wait until all three files appear in the list.
4. In the commit message box, type a short message such as `Add mk1`.
5. Make sure Commit directly to the main branch is selected, then click Commit changes.

### 3. Turn on GitHub Pages
1. In the repository, click the Settings tab.
2. In the left sidebar, click Pages.
3. Under Build and deployment, set Source to Deploy from a branch.
4. Under Branch, select main and leave the folder as / (root).
5. Click Save.

### 4. Wait for the site to publish
1. Click the Actions tab to watch progress. An amber dot means it is building, and a green tick means it has finished. This usually takes a few minutes.
2. Return to Settings -> Pages and refresh. The text Your site is live at appears with your link.

### 5. Visit the site
Open the link, which looks like `https://<your-username>.github.io/my-first-site/`.

### 6. Update the site later
Edit a file on GitHub (open it and click the pencil icon) or upload a new version, then commit. GitHub Pages republishes automatically.

## Setup and configuration requirements

**Required:**
- A free GitHub account
- A web browser
- A text editor (I used Visual Studio Code, but any editor works)
- The website files: `index.html`, `style.css` and `image.jpg`

**Not required:**
- Git or any command-line tools
- API keys or other credentials
